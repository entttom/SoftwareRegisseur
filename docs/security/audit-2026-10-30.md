# Sicherheitsprüfung 2026-10-30 – Software Regisseur

**Umfang:** `Packages/*/Sources`, `Services/SoftwareRegisseurAgentService/{Core,Sources}`, `Apps/*/Sources`, `Apps/SoftwareRegisseur-macOS/Logic`, `project.yml`, `Config/*.xcconfig`, Entitlements.
**Methode:** Code lesen und gezielt suchen. Bezug: [Bedrohungsmodell](bedrohungsmodell.md).
**Einschränkungen:**
- Während der Prüfung hatte der Mac das Prozesslimit pro Benutzer erreicht. Ab etwa der Hälfte der Prüfung lief kein Shell-Befehl mehr, auch kein `grep`. **Es wurden keine Tests ausgeführt.** Spätere Prüfschritte beruhen nur auf dem Lesen einzelner Dateien.
- Die Suche nach `privacy: .public`, `print(`/`NSLog(`, allen `kSecAttrAccessible`-Stellen und allen `URLSession`-Basis-URLs ist **nicht vollständig** (SR-SEC-18).
- Nicht verändert: Code, Tests, Konfiguration. Diese Prüfung hat nur `docs/security/` angelegt.

Schweregrade: **kritisch** (Fernausführung ohne Benutzerhandlung) · **hoch** (Grenze aus L2/L3/Q1 überwindbar, realistisch ausnutzbar) · **mittel** (Grenze mit Zusatzbedingung überwindbar) · **niedrig** (Härtung, begrenzter Schaden) · **info**.
